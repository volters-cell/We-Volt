    EU Tracker

    Every vote of the European Parliament, member by member. Each record is a JSON file in the public repository, and each one names the source it was read from.

    Source
    European Parliament open data portal, data.europarl.europa.eu
    Coverage
    Every vote of the current term, from 16 July 2024
    Updated
    Automatically, after each plenary sitting
